FEATURES

一个自用浏览器的自我修养

①多标签 + 起始页

每标签独立 WebView，卡片式切换，重启后恢复。起始页带搜索框与收藏宫格，主页可改为任意 URL。

②规则代理

多出口（HTTP / SOCKS5）+ 自动切换规则，支持粘贴或 URL 导入 AutoProxy / gfwlist（base64 自动解码），浏览器菜单一键快切，即时生效。

③广告拦截

EasyList + EasyList China，域名拦截配合元素隐藏。总开关、规则更新、站点白名单都在设置里，也能对当前站点单独关闭。

④密码管理

登录表单自动捕获（含无 form 的 fetch 登录），询问后经 Android Keystore AES-256-GCM 加密落盘，下次自动填充；随时可清理。

⑤桌面模式与个性化

一键切换桌面 / 移动 UA，可保存多套自定义预设；字号 50–200%、三种字体、亮暗主题、网页自动深色。

⑥干净自用

无账号、无统计、无开屏。7 种界面语言，内置 eruda 与 chrome://inspect 远程调试，开发者友好。

PRIVACY

数据只留在本机

设置、书签、浏览历史都存在本地，已保存密码经 Android Keystore 加密。应用无账号、无统计、无任何上传。 联网只发生在三处：浏览网页本身、在线更新广告拦截规则（EasyList）、下载你配置的代理规则列表。
